Oduna is a NixOS flake for a self-hosted home and dev server: encrypted ZFS storage, single sign-on and a curated set of apps, declared in one repository and rebuildable on any hardware from Git plus a data backup.

View on GitHub Read the vision

Declared

The whole server lives in one repository. Change it with a commit, roll it out with a deploy.

Yours

Self-hosted on your own hardware, with your data in encrypted pools and your own offsite backups.

Single sign-on

One identity provider in front of every app, with a break-glass local admin next to it.

Rebuildable

Lose the machine, keep the repository and a backup, and bring everything back on new hardware.

Oduna is early. It runs a real family deployment today and is being refactored towards a reusable app contract, so expect breaking changes.
