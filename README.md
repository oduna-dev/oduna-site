# oduna.dev

Landing page for [Oduna](https://github.com/oduna-dev/oduna), served with GitHub Pages at <https://oduna.dev>.

Plain static files, no build step:

- `index.html`: the page (dark and light via `prefers-color-scheme`)
- `assets/`: logo (mark, lockups with outlined wordmark), favicons, social image, self-hosted Syne font (SIL OFL, see `assets/fonts/syne-OFL.txt`)
- `CNAME`: custom domain

## Brand

| Role                                    | Hex                    |
| --------------------------------------- | ---------------------- |
| Abyss (dark background)                 | `#07122B`              |
| Navy (surface, text on light)           | `#0B1F4A`              |
| Royal                                   | `#1E4FD8`              |
| Azure (accent on dark)                  | `#4C8DFF`              |
| Ice (text on dark)                      | `#DCE8FF`              |
| Paper (light background)                | `#F5F8FF`              |
| Ember to Blossom (warm accent gradient) | `#FFB36B` to `#FF6FA8` |

Wordmark: Syne Medium (500), lowercase.
